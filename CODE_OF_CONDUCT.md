# Code of Conduct

CSS Dojo follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique code and never people. Harassment of any kind is not tolerated.

Report problems privately to the maintainer through GitHub (the profile of @AbhishekBalija). Reports are kept confidential.
