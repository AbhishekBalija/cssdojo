# CSS Dojo v0.1.0 (draft release notes)

The first playable version of CSS Dojo: rebuild small, real UI in HTML and CSS and get scored on look and behaviour.

## Highlights
- **30 challenges across five belts** (white, yellow, green, brown, black), each with a golden set proving it scores as intended (195 answers).
- **Daily kata**: 14 kata on a looping cycle, a board per UTC day, and a streak.
- **Scoring** in a pinned Chromium: 70% visual match (shape, colour, edges, with one-pixel drift forgiven) and 30% outcome checks (hover, focus visible, contrast, target size, semantics, real text), with a hint for every failed check.
- **Play screen**: CodeMirror editor, live output with hover and focus preview, slide and diff over the target, live-target replay, attempts, solutions after 90.
- **Accounts**: GitHub and Google sign-in; guest progress moves to your account on first sign-in.
- **Leaderboards and belts**: today's kata, overall and per challenge; belt progress and public profiles.
- **Review pages**: `/gallery` for every challenge and kata, `/assets` for the brand set.
- **Deploy**: one Docker service on Render free with Neon Postgres, plus a static client site.

## Known limits
- Free plan: the first request after 15 idle minutes takes about a minute; one Submit is scored at a time.
- On the static site, Safari and Firefox block the cross-site session cookie. Use the API URL as the app link (see ADR 0005).
- Best on desktop; phones get a pane switcher and a note.
